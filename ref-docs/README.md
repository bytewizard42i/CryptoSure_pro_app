# CryptoSure Third-Party Sources of Truth

This directory records authoritative external sources that guide CryptoSure's legal,
regulatory, insurance, security, and commercial planning.

## How to use this directory

- Follow the original source link before making a legal, pricing, licensing, or launch
  decision.
- Treat each note as a navigation and context record, not as a replacement for the
  regulator's current page, statute, rule, or professional advice.
- Check the recorded verification date. Re-verify time-sensitive information before use.
- Keep DemoLand assumptions separate from carrier-approved policy terms.
